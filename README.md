# ShirtCraft — jQuery + PHP + MySQL (XAMPP)

Folder name in `C:\xampp\htdocs\` : `stallion`  →  http://localhost/stallion/

See the step-by-step guide in the chat. Quick version:
1. Start **Apache** and **MySQL** in the XAMPP Control Panel.
2. phpMyAdmin → Import → `database.sql`.
3. Open http://localhost/stallion/
Settings (DB password, bank details): `includes/config.php`.
